# MAISON MOYA

This repository is structured for a clean split between the existing frontend and a future backend.

## Repository structure

- frontend/ — Next.js e-commerce application
- backend/ — planned API service, not implemented yet
- database/ — migrations, schema, and seed plans
- docs/ — architecture and deployment notes
- .gitignore — shared ignore rules

## Frontend

From the frontend directory:

```bash
cd frontend
npm install
npm run dev
```

## Backend

No production backend is implemented yet. The backend folder contains a placeholder structure and implementation plan only.

See [backend/README.md](backend/README.md) for the future API roadmap.
